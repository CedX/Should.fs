# Changelog

## Version [2026.12.0](https://github.com/CedX/Should.fs/compare/v2026.11.1...v2026.12.0)
- Improved the signature of generic functions.
- Replaced the `expectedType` parameter of the `beAssignableTo` and `beOfType` functions by a generic type parameter.
- Replaced the `exceptionType` parameter of the `notThrow` and `throw` functions by a generic type parameter.

## Version [2026.11.1](https://github.com/CedX/Should.fs/compare/v2026.11.0...v2026.11.1)
- All functions of the `AsyncShould` module now uses `async` expressions.

## Version 2026.11.0
- Initial release.
